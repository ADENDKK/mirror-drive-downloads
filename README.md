# Mirror Drive downloads

Official public release files for **Mirror Drive** by Plainloop Labs.

The recommended installation flow is the Windows **Mirror Drive USB Creator**. It downloads and verifies the current boot image before writing it to a selected USB drive.

> **Test software:** Mirror Drive is under active development. Creating the bootable USB permanently erases all existing data on the selected USB drive. Keep backups and verify the selected drive before continuing.

Product page: <https://plainloopstudios.com/en/projects/mirror/>

## Release verification

Release assets include SHA-256 digests. The USB Creator also verifies the complete boot image before and after writing it.
